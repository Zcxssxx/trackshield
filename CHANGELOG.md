# Changelog

This file records user-visible changes. The project has not made a tagged
release yet.

## [0.1.0] - Unreleased

- Add an offline native CLI and reusable MoonBit library for GPX 1.0/1.1
  collection inspection.
- Report repeated start/end observations across distinct input files and
  metadata-category presence without showing coordinates or metadata values by
  default.
- Render deterministic text and JSON audit reports.
- Preview or explicitly write redactions for a user-specified circle, with
  selected metadata removal, separate retained track runs, bounded input, and
  staged output validation.
- Add authored synthetic examples, test fixtures, documentation, and
  dependency provenance.

This unreleased version is limited to documented GPX namespaces and a native
CLI. See [formats and limits](docs/formats-and-limits.md) for unsupported cases
and filesystem limitations.
